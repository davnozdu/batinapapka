Поиск названий · ThePornDB

Сначала проверяется каталог по отпечатку файла и метаданным. Если совпадения нет, используется Brave. Видеофайл не отправляется; в каталог передаются отпечаток и поисковые названия.

Telegram-бот

Бот принимает ссылки в личном чате только от разрешённых ID. Одна ссылка — одно задание; итоговое уведомление приходит после всей обработки.

Узнать свой ID можно через @userinfobot. Бот игнорирует других пользователей и группы.

Команды: /active, /status, /queue, /pause ID, /resume ID, /cancel ID. Боту нужен свободный long polling: не запускайте одновременно второй экземпляр с тем же токеном.

Свежие файлы младше 60 секунд будут пропущены. Переименование использует ThePornDB, затем Brave.
